## I build the infrastructure AI agents run on.

I'm **Saidu Bello**, a platform and systems engineer and founding engineer at **[ORGN](https://orgn.com)**. I work across cloud infrastructure, confidential computing, identity, and the systems that turn AI capabilities into dependable products.

My scope runs from `terraform plan` to production traffic: **Kubernetes and GitOps, Rust and Go services, hardware-isolated sandboxes, and secure delivery pipelines**.

### Selected engineering work

| Area | What I've built and operated |
| :--- | :--- |
| **Confidential computing** | Intel TDX sandboxes and a Go remote-attestation service, with node-local brokers and a public verification gateway. |
| **AI infrastructure** | An LLM gateway routing **220+ models across four providers**, with metering, spend caps, and cancellation-safe billing in Rust. |
| **Cloud platforms** | Multi-cloud Kubernetes across GKE and DigitalOcean; Terraform across GCP, DigitalOcean, and Alibaba Cloud; Argo CD reconciliation and keyless CI/CD. |
| **Identity & security** | An OAuth 2.1 / OIDC authorization server with passkeys and organization RBAC; a **zero-downtime blue-green migration** to GKE and Cloud SQL. |
| **Reliability & cost** | Prometheus, Grafana, OpenTelemetry, and ClickHouse; **50%+ infrastructure cost reductions** through right-sizing, consolidation, and scale-to-zero policies. |
